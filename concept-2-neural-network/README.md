# 🧠 Neural Nexus - Concept 2

> Living AI visualization with interactive neural networks and pulsing connections.

## 🎨 Concept Overview

Neural Nexus presents your software company as a living, breathing neural network. Features:

- **Interactive 3D Neural Network** - Click nodes to activate electrical surges
- **Pulsing Neurons** - Nodes that pulse and glow with life
- **Electric Connections** - Dynamic lines connecting related services
- **Particle Systems** - Flowing data visualization
- **Electric Mouse Trail** - Cybernetic cursor effects
- **Animated Background Network** - Canvas-based particle connections

## ✨ Key Features

- 🧠 **Living Network Visualization** (Three.js + React Three Fiber)
- ⚡ **Electrical Pulse Animations**
- 🌐 **Dynamic Node Connections**
- 🎬 **GSAP Character Animations**
- 🎨 **Cyberpunk Aesthetic** (Cyan, purple, magenta gradients)
- 📱 **Fully Responsive**

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **3D**: Three.js + React Three Fiber
- **Animation**: GSAP + Framer Motion
- **Visualization**: D3.js for data
- **Styling**: TailwindCSS
- **Language**: TypeScript
