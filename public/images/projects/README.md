# Project Images

Add your project screenshots here!

## Required Images

For each project in `src/data/projects.json`, add:

1. **Original image** (JPG or PNG):
   - `ai-video-studio.jpg`
   - `wine-vault.jpg`
   - `poker-hub.jpg`
   - `flow-master.jpg`

2. **Run optimization script**:
   ```bash
   npm run optimize-images
   ```

   This will automatically generate:
   - WebP versions (smaller file size)
   - 2x versions for retina displays

## Image Guidelines

- **Aspect ratio**: 16:9 (e.g., 1600x900px)
- **Format**: JPG or PNG
- **Size**: Under 500KB (will be optimized)
- **Content**: Screenshots, mockups, or hero images

## Example

```
public/images/projects/
├── ai-video-studio.jpg       # Your original
├── ai-video-studio.webp      # Generated by script
├── ai-video-studio@2x.webp   # Generated by script
├── wine-vault.jpg
├── wine-vault.webp
└── ...
```

The website will automatically use WebP when supported, with JPG fallback.
