# 🌊 softwave dev - Creative Landing Page

A cutting-edge, creative landing page for a web development company that showcases exceptional design skills and modern web technologies.

## ✨ Features

### 🎨 Visual Design
- **Glassmorphism Effects** - Frosted glass UI elements with backdrop blur
- **Animated Wave Background** - Liquid wave animations using SVG
- **3D Card Transforms** - Interactive cards with depth and perspective
- **Gradient Animations** - Dynamic, shifting color gradients
- **Particle System** - Floating particles that create ambient motion
- **Custom Cursor** - Interactive cursor that responds to page elements

### 🎭 Interactive Elements
- **Scroll-Triggered Animations** - Elements reveal as you scroll using Intersection Observer
- **3D Tilt Effect** - Cards tilt based on mouse position
- **Ripple Effects** - Button clicks create water ripple animations
- **Parallax Scrolling** - Depth through layered movement
- **Counter Animations** - Stats count up when scrolled into view
- **Hover Transformations** - Smooth scale, translate, and glow effects
- **Image Parallax** - Portfolio images move with mouse

### 🚀 Technical Highlights
- **Pure HTML/CSS/JavaScript** - No frameworks, maximum creativity
- **Responsive Design** - Mobile-first approach, works on all devices
- **Performance Optimized** - Debounced scroll events, efficient animations
- **Semantic HTML** - Proper markup structure
- **CSS Custom Properties** - Easy theme customization
- **Smooth Animations** - RequestAnimationFrame for 60fps performance

### 🎯 Sections
1. **Hero** - Eye-catching introduction with animated code preview
2. **Services** - 4 glassmorphic cards showcasing offerings
3. **Work** - Bento grid layout with portfolio showcase
4. **Tech Stack** - Technologies organized by category
5. **CTA** - Call-to-action with rotating gradient effect
6. **Footer** - Complete site navigation and links

### 🎁 Easter Eggs
- **Konami Code** - Try ↑↑↓↓←→←→BA for a surprise!

## 🎨 Customization

### Change Colors
Edit the CSS custom properties in `styles.css`:

```css
:root {
    --color-purple: #your-color;
    --color-cyan: #your-color;
    /* etc... */
}
```

### Adjust Animations
Modify animation durations and timing functions in `styles.css`:

```css
--transition-smooth: all 0.4s cubic-bezier(0.4, 0, 0.2, 1);
```

### Update Content
Edit the HTML in `index.html` to match your brand and services.

## 🌟 Key Design Decisions

### Why Glassmorphism?
- Modern, elegant aesthetic
- Creates depth without heavy visuals
- Works well with dark themes
- Trending in 2025 design

### Why Custom Cursor?
- Enhances interactivity
- Adds personality to the experience
- Guides user attention
- Creates memorable impression

### Why Wave Theme?
- Plays on company name "softwave"
- Represents fluidity and innovation
- Creates motion and energy
- Differentiates from standard corporate sites

## 📊 Performance

- Debounced scroll events for efficiency
- RequestAnimationFrame for smooth 60fps animations
- Optimized particle count (50 particles)
- Lazy-loaded intersection observers
- Minimal DOM manipulations
