# 💧 Liquid Interface - Concept 5

> Where design flows like water. Organic, adaptive, alive.

## 🎨 Concept Overview

Liquid Interface presents software as a living fluid that morphs and adapts:

- **Fluid 3D Blobs** - Morphing metaball simulations
- **Ripple Cursor** - Water-like mouse interactions
- **Morphing Shapes** - CSS blob animations
- **Gradient Shifts** - Dynamic color transitions
- **Distortion Materials** - Three.js mesh distortions
- **Organic Flow** - Seamless, natural movements

## ✨ Key Features

- 💧 **Liquid 3D Scene** (Three.js metaballs)
- 🌊 **Ripple Effects** (Canvas cursor)
- ✨ **Blob Morphing** (CSS animations)
- 🎨 **Gradient Shifts** (Dynamic colors)
- 🌈 **Distortion Materials**
- 📱 **Fully Responsive**

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **3D**: Three.js + React Three Fiber
- **Materials**: MeshDistortMaterial
- **Animation**: Framer Motion
- **Styling**: TailwindCSS
- **Language**: TypeScript

## 🚀 Installation

```bash
cd concept-5-liquid-interface
npm install
npm run dev
```

Visit `http://localhost:3005`
